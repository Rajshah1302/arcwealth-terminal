# ARCWEALTH contracts (Solidity 0.8.28, OpenZeppelin v5, Arc Testnet 5042002)

Shared interfaces live in `contracts/interfaces/IArcWealth.sol` (do not change signatures). All USDC amounts are the 6-decimal ERC-20 view of `0x3600000000000000000000000000000000000000`. Never use `msg.value` or `address(this).balance`; contracts must not accept native value (no `receive`/`payable`). Never send to `address(0)`. No `selfdestruct`. Pull-based claims only: no loops that push funds to many recipients.

Demo underlyings use 18 decimals. Prices are USD with 8 decimals (`price8`). Conversions:
`tokenAmount18 = usdc6 * 1e12 * 1e8 / price8` and `usdc6 = token18 * price8 / 1e20`.

Directory layout: `contracts/demo/`, `contracts/core/`, `contracts/modules/`, `contracts/interfaces/`. Use custom errors. Natspec on every external function. Each demo contract implements `isDemo() returns (true)`.

## Honesty tiers
LIVE-TESTNET: USDC, EURC, cirBTC, WETH (real Arc contracts we do not own). DEMO-ONCHAIN: everything in `contracts/demo/` and `contracts/modules/` stand-ins. SIMULATED-OFFCHAIN: backend prices, backtests.

## Roles (OZ AccessControl)
`DEFAULT_ADMIN_ROLE` is held by a `ArcWealthTimelock` (OZ TimelockController, 600 s min delay) after setup. `MANAGER_ROLE`, `KEEPER_ROLE`, `PAUSER_ROLE`. No role may move investor funds or shares arbitrarily or bypass deposit/withdraw. The vault only sends USDC to (a) whitelisted modules, (b) the entitled user on withdraw / claim. There is no rescue, sweep, or arbitrary-call function.

## contracts/demo

### DemoERC20 (`DemoERC20.sol`)
`constructor(string name, string symbol, uint8 decimals_, address admin, uint256 faucetAmount)`. OZ ERC20 + ERC20Burnable + AccessControl. `MINTER_ROLE` (router). `faucet()`: mints `faucetAmount` to msg.sender, once per 1 hour per address (revert `FaucetCooldown`). `mint(to, amount)` MINTER only. `isDemo()` true. `decimals()` returns the constructor value.

### DemoPriceOracle (`DemoPriceOracle.sol`) implements IPriceSource, IDemo
`constructor(address admin, address keeper)` grants DEFAULT_ADMIN and KEEPER. `STALENESS = 1 hours`. `setPrice(token, price8)` KEEPER only: first price any value > 0; afterwards `|new - old| <= old * 10%` else revert `StepTooLarge` (admin may `resetPrice` via DEFAULT_ADMIN for re-seeding). `setPrices(address[], uint256[])`. `getPrice(token)` reverts `StalePrice(token, age)` when `block.timestamp - updatedAt > STALENESS` and `PriceNotSet` when unset. `lastUpdated(token)`. `getPriceUnsafe(token) returns (price8, updatedAt)`. Also stores `vol30dBps[token]` (`setVol` KEEPER, informational, simulated-offchain realised vol). Events `PriceSet(token, price8, ts)`.

### DemoSwapRouter (`DemoSwapRouter.sol`) implements IExecutionAdapter, IDemo
`constructor(address usdc, address oracle, address admin)`. MANAGER registers tokens (`registerToken(token)`; unregistered tokens revert `TokenNotSupported`). `FEE_BPS = 30` (0.3%). Buy: pull USDC from msg.sender (SafeERC20), `fee = usdcIn*30/10000`, mint `tokenOut` (router is MINTER of every demo token) to `to`. Sell: `burnFrom` tokens held by msg.sender (needs allowance), pay USDC from the router's USDC reserve (reverts `InsufficientLiquidity` if short), fee withheld. `minOut` slippage checks. `to != address(0)`. Oracle staleness reverts bubble up. Quote functions mirror the math. `fundReserve(uint256)` pulls USDC from anyone. USDC reserve = `usdc.balanceOf(this)` (ERC-20 view only). Router never holds native value.

### DemoBondIssuer (`DemoBondIssuer.sol`) implements IBondIssuer
One contract that manages bond series (units are internal, 1 unit = 1 USDC-unit, 6 dec). `constructor(address usdc, address admin)`. MANAGER `createSeries(string name, string rating, uint16 couponBps, uint64 maturity)` (maturity 14 to 90 days from now). `subscribe`, `unitsOf`, `pendingCoupon = units * couponBps * (min(now, maturity) - lastClaim) / (10_000 * 365 days)` (Actual/365, simple), `claimCoupon`, `redeem`. `lastClaim[id][holder]` set when units are added (accrue first, weighted by tracking an `accrued[id][holder]` carry). Coupons and principal paid from the issuer's USDC balance; revert `InsufficientReserve` if short. `fundReserve(amount)`. Events `Subscribed`, `CouponPaid(id, holder, amount)`, `Redeemed`. Early redemption at par plus accrued is allowed (DEMO feature, documented). Reserve accounting: `totalOutstanding` informational view.

### DemoOptionsCounterparty (`DemoOptionsCounterparty.sol`) implements IOptionsCounterparty
`constructor(address usdc, address admin)`. Role `MODULE_ROLE` (granted by admin to covered-call modules). `payPremium(to, premium, notional)`: require `premium <= notional * maxPremiumBps / 10_000` (default 1500) and `premium <= availableLiquidity()`; transfers real USDC. `settleAssignment(underlying, qty, strikeValue, from)`: `transferFrom(from, this, qty)` of the demo token then pays `strikeValue` USDC to `from`; reverts `InsufficientLiquidity` if short. `recycle(token, amount)` KEEPER: sells held demo tokens through a router set at construction/`setRouter` (admin) to replenish USDC. `fundReserve`. `availableLiquidity = usdc.balanceOf(this)`.

### DemoLendingPool (`DemoLendingPool.sol`) implements IDemo (P1)
USDC supply + borrow of registered collateral tokens (cirBTC, dBTC). `supply/withdraw` USDC, `depositCollateral/withdrawCollateral`, `borrow(usdcAmount)`, `repay(usdcAmount)`, `liquidate(user, repayAmount)`. LTV 70%, liquidation threshold 80%, 5% liquidation bonus, oracle from IPriceSource (cirBTC priced via oracle key too). Utilisation interest model: base 2% APR, slope1 up to 80% kink, slope2 steep above; supply APR = borrowAPR * utilisation * 0.9. Interest accrues per second to a global index. Views: `healthFactor(user)` (1e18 scale), `utilisation()`, `supplyApr()`, `borrowApr()`. Pull only.

## contracts/core

### ArcWealthTimelock (`ArcWealthTimelock.sol`)
`contract ArcWealthTimelock is TimelockController` with a constructor `(uint256 minDelay, address[] proposers, address[] executors, address admin)`. Compile target for artifact only.

### RiskManager (`RiskManager.sol`) implements IRiskManager
`constructor(address admin)`. All setters are `onlyRole(DEFAULT_ADMIN_ROLE)` (timelock) except none for MANAGER. Per-strategy (vault address) config: `setLimits(strategy, minDeposit, tvlCap, userCap, minIdleBps)` (defaults for S1: 10e6, 1_000e6, 250e6, 1000), `setSleeveBand(strategy, sleeve, minBps, maxBps)`, `setAssetMaxBps(strategy, token, bps)`. Per-module `setCallLimits(module, CallLimits)`. `maxDeposit(strategy, tvl, userAssets) = min(tvlCap > tvl ? tvlCap - tvl : 0, userCap > userAssets ? userCap - userAssets : 0)`. `checkCoverage(held, shortAfter)` pure: revert `CoverageViolation(held, shortAfter)` if `shortAfter > held`. Event `LimitsChanged`. Validate bands (min <= max <= 10000) and minIdle >= 1000 bps (10%) floor enforced.

### StrategyManager (`StrategyManager.sol`) implements IStrategyManager
`constructor(address admin)`. Registered strategies keyed by vault address. `registerStrategy(vault, string name, uint16[] moduleWeights, bytes32 configHash)` DEFAULT_ADMIN. `setModuleWeights(vault, uint16[] weights, bytes32 newHash, string reason)` MANAGER; weights must sum to 10000 and each be within RiskManager sleeve bands (`IRiskManager.sleeveBand(vault, i)` if bands set); emits `StrategyConfigChanged(vault, oldHash, newHash, weights, msg.sender, reason)`. `setAssetWeights(vault, tokens[], bps[], newHash, reason)` MANAGER, each `<= assetMaxBps`. `setOptionsAvailable(vault, token, bool)` MANAGER (dCOPR must remain false: cannot be enabled if the token is flagged `noOptions` by admin). Regime: `postRegimeInputs(uint16 vol30dX100, bool trendUp, uint16 benchmarkRateBps, uint16 idleRatioBps)` KEEPER, where `vol30dX100` is annualised realised vol in percent times 1 (e.g. 45 = 45%). Regime id: 0 RiskOff (vol > 80 or !trendUp with vol > 30... use: vol > 80 || !trendUp), 1 High (60 <= vol <= 80), 2 Normal (30 < vol < 60), 3 Calm (vol <= 30 && trendUp). Emits `RegimeChanged`. Regime table (cash, tbill, puts) in bps: RiskOff 5000/4000/1000, High 3000/3000/4000, Normal 2500/5500/2000, Calm 2000/8000/0. `tacticalOverride(vault, int16 cashDeltaBps, int16 tbillDeltaBps, string reason)` MANAGER with `|delta| <= 1000`; puts absorbs the remainder; result must stay non-negative and sum 10000; stored per strategy; emits `StrategyConfigChanged`. `tacticalAllocation(vault)` returns table row plus override. `configHash(vault)`, `targetWeights(vault)`, `assetWeights(vault)`, `optionsAvailable(vault, token)`, `currentRegime()`.

### InvestorVault (`InvestorVault.sol`) implements IInvestorVault
`constructor(address admin)`. `registerStrategy(address vault, bytes32 disclosureHash)` DEFAULT_ADMIN. `acceptDisclosure(address strategy, bytes32 hash)` by user: hash must equal the strategy's registered `disclosureHash`; stores `accepted[user][strategy]`; emits `DisclosureAccepted(user, strategy, hash)`. `recordDeposit/recordWithdraw` only callable by registered strategy vaults (the vault must `require(hasAccepted)` itself). Cost basis: `costBasis[user][strategy]` in USDC; on withdraw reduce proportionally to shares redeemed using `sharesHeld[user][strategy]`. Views `positionOf(user, strategy) returns (costBasis, shares, acceptedAt)`. No custody of USDC or shares.

### SIFStrategyVault (`SIFStrategyVault.sol`)
ERC-4626 (OZ `ERC4626` + `AccessControl` + `Pausable` + `ReentrancyGuard`). `constructor(IERC20 usdc, string name, string symbol, address admin, address feeRecipient, IInvestorVault investorVault, IRiskManager risk, IStrategyManager manager)`. `_decimalsOffset() = 6` (inflation-attack protection; shares have 12 decimals; initial share price 1.0 USDC). `sharePrice() = convertToAssets(10 ** decimals())` (6-dec USDC per 1.0 share).
- `totalAssets() = usdc.balanceOf(this) + sum(module.totalValue())`.
- Modules: `address[] modules`; `addModule(address)` / `removeModule(address)` DEFAULT_ADMIN (timelock) only; removal requires `totalValue()==0`. Module must report `vault()==address(this)` and `isDemo()`.
- Deposit/mint path: `whenNotPaused nonReentrant`; call `checkpointFee()` first; require `assets >= risk.minDeposit(this)`; `assets <= maxDeposit(receiver)`; require `investorVault.hasAccepted(receiver, this)`; after mint `investorVault.recordDeposit(receiver, assets, shares)`; then `_route(assets)`.
- `maxDeposit(receiver)`: 0 if paused else `risk.maxDeposit(this, totalAssets(), convertToAssets(balanceOf(receiver)))`. `maxMint` consistent.
- `_route`: invest `assets` into modules per `manager.targetWeights(this)` but always keep idle >= `minIdleBps` of NAV; for each module `try deposit` with `forceApprove(module, amount)`; on failure emit `RouteFailed(module, amount, reason)` and leave funds idle (never revert the user deposit because a module failed, e.g. stale oracle). Reset approval to 0 after.
- Withdraw/redeem: instant only up to idle buffer: `maxWithdraw(owner) = min(convertToAssets(balanceOf(owner)), idle)`, `maxRedeem(owner) = min(balanceOf(owner), convertToShares(idle))`. `_withdraw` calls `investorVault.recordWithdraw`. Not blocked by pause (users can always exit).
- Large exits: `requestRedeem(shares)` escrows shares in the vault (one open request per user, additive); `cancelRedeem()` returns them; `fulfillRedeem(address user)` KEEPER: assets = convertToAssets(escrowed shares); if idle < assets, pull from modules (`withdraw` best-effort); require idle >= assets else `InsufficientUnwound`; burn the shares, `claimable[user] += assets`, `recordWithdraw`; `claimRedeem()` by user pulls USDC (check-effects-interactions). Keeper cannot redirect proceeds.
- `unwind(uint256 amount)` KEEPER: pull USDC from modules (most liquid first) to idle. `rebalance()` KEEPER: move toward `targetWeights` using module `withdraw` for overweight and `deposit` for underweight, respecting min idle; try/catch.
- Fee: `FEE_BPS = 100` per year in shares. `checkpointFee()` (public, anyone): `feeShares = totalSupply * FEE_BPS * dt / (10_000 * 365 days)` minted to `feeRecipient`; `lastFeeTs` updates; emit `FeeCheckpoint(feeShares, dt, sharePrice)`. No entry or exit fee.
- Pause: `PAUSER_ROLE` pause/unpause deposits only (also pauses `_route`/`rebalance`).
- Views: `idle()`, `moduleCount()`, `moduleBreakdown() returns (address[] mods, uint256[] values)`, `pendingRedeem(user)`.
- Constraints: the contract must never call anything that sends USDC elsewhere than module deposits and entitled users. `renounceRole` is allowed, `DEFAULT_ADMIN` cannot move funds.

## contracts/modules (all `IStrategyModule`; only the vault may call `deposit`/`withdraw`; KEEPER functions use the VAULT's KEEPER role via `IAccessControl(vault).hasRole(KEEPER_ROLE, msg.sender)`)

### BondInvestmentModule
`constructor(address usdc, address vault, address issuer, uint256[] seriesIds)`. `deposit` splits equally across non-matured series via `issuer.subscribe`. `totalValue = usdc.balanceOf(this) + sum(units + pendingCoupon)` over series. `liquidValue = usdc balance + sum(units + pending)` (early redemption at par permitted by the demo issuer, capped by issuer reserve; use try/catch). `withdraw(amount)`: cash first then `issuer.redeem`. `claimCoupons()` public: calls `issuer.claimCoupon` for each series (USDC lands in the module; emits `CouponsClaimed(total)` per series). `rollMatured()` KEEPER: redeem matured series and re-subscribe to active ones (or hold cash).

### CoveredCallModule
`constructor(address usdc, address vault, address router, address oracle, address counterparty, address risk, address[] underlyings, uint16[] underlyingBps)`. `deposit` splits USDC across underlyings via `IExecutionAdapter` (min out via quote minus 1%). `writeCall(address underlying, uint256 qty, uint256 strike, uint64 expiry, uint256 premium)` KEEPER: check underlying whitelisted; `CallLimits l = risk.callLimits(this)`; `strike*10000/spot` within `[l.minStrikeBps, l.maxStrikeBps]`; expiry within `[now+l.minExpiry, now+l.maxExpiry]`; shorts per asset `<= maxShortsPerAsset`; coverage: `risk.checkCoverage(token.balanceOf(this), openShortQty[underlying] + qty)` (revert if short > unlocked); `counterparty.payPremium(this, premium, qty*spot/1e20)`; record `Call{underlying, qty, strike, expiry, premium, counterparty, status}`; emit `CallWritten(id, underlying, qty, strike, expiry, premium, counterparty)`. Oracle price must be fresh (stale reverts). `settle(id)` KEEPER after expiry: spot fresh; if `spot > strike`: approve counterparty and `counterparty.settleAssignment(underlying, qty, strike*qty/1e20..., address(this))` (USDC value = `qty * strike / 1e20`), status Assigned; else Expired worthless. Emit `CallSettled(id, spot, assigned)`. `reinvest(underlying, usdcAmount)` KEEPER buys more underlying from module cash (used for S3's 50% premium reinvest). `totalValue = usdcBalance + sum(held * spot / 1e20) - sum(open call liability = max(spot - strike, 0) * qty / 1e20)`; floor at 0 per component; if oracle stale then `totalValue` reverts (the vault catches it where needed; vault `totalAssets` uses try/catch on modules and counts last cached value? NO: keep it simple, the module caches `lastGoodValue` on every state change and `totalValue()` returns the cached value if the oracle is stale). `liquidValue` = cash + unlocked underlying value. `withdraw(amount)`: cash first then sell unlocked underlying through the router. Views: `callCount()`, `getCall(id)`, `openShort(underlying)`.

### TacticalSleeveModule
`constructor(address usdc, address vault, address router, address oracle, address manager, address tbill)`. Holds USDC cash and dTBILL; `rebalanceTactical()` KEEPER reads `manager.tacticalAllocation(vault)` and trades dTBILL via router so that tbill value ~= tbillBps of module NAV (tolerance 2%); `putsBps` is only reserved USDC collateral (`putCollateral()` view, no on-chain puts; SLBM is a placeholder, documented). `totalValue = cash + tbill * price / 1e20` (cached fallback if stale). `withdraw` uses cash first then sells dTBILL.

### AssetAllocatorModule (S2)
`constructor(address usdc, address vault, address router, address oracle, address manager, address risk, address[] tokens)`. `deposit` buys per `manager.assetWeights(vault)`; `rebalance()` KEEPER; asset share limited by `risk.assetMaxBps`. `setOptionsAvailable` is read from the manager; `recordOverlay(token, kind, notionalBps, reason)` KEEPER emits `OverlayRecorded` and reverts `OptionsDisabled(token)` if the manager says options are unavailable (dCOPR). On-chain options overlay for S2 is intentionally recorded-only (documented). `totalValue = cash + sum(qty * price / 1e20)` with cached fallback.
